# My Money Planner — Rough Draft

My Money Planner is a simple budgeting app prototype for keeping track of income, bills, expenses, and savings. It helps users see how much money is left after planned spending.

## Features
- Dashboard with money remaining
- Add and review expenses
- Track monthly bills and due dates
- Track a savings goal
- Edit income and load sample data
- Save entries in this browser's local storage

## How to use
Open `index.html` in a browser. Enter your monthly income, add upcoming bills and expenses, and set a savings goal. The dashboard updates automatically.

## Deployment with GitHub Pages
1. Create a public GitHub repository named `My-Money-Planner`.
2. Upload `index.html` and `README.md` to the root of the repository, and commit them to the `main` branch.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, set branch `main` and folder `/(root)`, and save.
5. Once published, the site will normally be available at `https://YOUR-USERNAME.github.io/My-Money-Planner/`.

## Prototype notes
This is a student prototype, not a bank app. It doesn't connect to financial accounts or make payments. Entries are stored only in the browser/device used, not synchronized across phones or computers. Do not enter passwords or account numbers.
